# 服务器与域名选购指南

给自托管元聊 YuanChat 的人一份「买什么机器、买哪家、域名怎么办」的参考。
配置要求部分是**按本仓 `deploy/docker-compose.prod.yml` 与各 Dockerfile 实际推导的**；
价格部分是**量级参考，不是实时报价**。

> ⚠️ **价格务必以官网为准**。本文价格为 2026-09 整理的大致区间，云厂商调价、
> 促销、地域差价都很频繁，国内云「新用户首年价」与「续费原价」常差 3-5 倍。
> 下单前自己核一遍。

## 一、先算清楚要多大的机器

### 1.1 运行时占用

生产 compose 常驻 8 个容器（`postgres` / `redis` / `minio` / `yuanchat-server` /
`yuanchat-web` / `yuanchat-admin` / `nginx` / `coturn`），外加按需执行的
`migrate`、`certbot`：

| 组件                        | 空载内存量级    |
| --------------------------- | --------------- |
| PostgreSQL 16               | 150-300 MB      |
| MinIO                       | 200-400 MB      |
| yuanchat-server（Go）       | 50-150 MB       |
| Redis 7                     | 20-50 MB        |
| nginx + web + admin（静态） | 40-90 MB        |
| coturn（空载，中继时涨）    | 20-50 MB        |
| **合计**                    | **约 0.5-1 GB** |

加上系统与 Docker 自身开销（约 0.3-0.5 GB），**空载实际占用约 1-1.5 GB**。

开可观测套件（`--profile observability`：Prometheus + Grafana + Loki）**再加 0.3-0.7 GB**。

### 1.2 构建期才是内存峰值 ← 最容易踩的坑

`deploy/install.sh` 执行的是 `docker compose up -d --build`，也就是
**镜像在你这台服务器上现编**，而不是拉现成的：

- `server/Dockerfile`：`golang:1.25-alpine` 里 `go build`
- `apps/web/Dockerfile`、`apps/admin/Dockerfile`：`node:22-alpine` 里
  `pnpm install --frozen-lockfile` + `pnpm --filter … build`（Vite/Rollup）

**两个前端的 Vite 构建是内存大户**，1 GB 的机器基本必 OOM，2 GB 也悬
（表现为构建到一半容器被杀，报 `exit code 137` 或 heap out of memory）。

三条出路，任选其一：

1. **直接买 4 GB 起**（最省事，本文所有推荐档位都按这个来）
2. 2 GB 机器**临时加 swap** 扛过构建：
   ```bash
   sudo fallocate -l 4G /swapfile && sudo chmod 600 /swapfile
   sudo mkswap /swapfile && sudo swapon /swapfile
   ```
   （构建慢但能过；`/etc/fstab` 里加一行可持久化）
3. **别在服务器上构建**：在本地或 CI 构建镜像推到镜像仓库，
   服务器只 `pull`。此时服务器 2 GB 够用

### 1.3 磁盘

| 用途                                           | 占用                                     |
| ---------------------------------------------- | ---------------------------------------- |
| 系统 + Docker 自身                             | 5-10 GB                                  |
| 构建产生的镜像与中间层（Go + Node）            | 5-15 GB（`docker builder prune` 可回收） |
| PostgreSQL 数据                                | 随消息量增长，起步几百 MB                |
| **MinIO 对象存储**（图片/语音/视频/文件/头像） | **主要增长点，取决于用户上传**           |

**40 GB 是能跑起来的下限，80 GB 起步更安心。** 媒体多的话优先加磁盘而不是内存。
本仓自带离线对象 GC（`server/cmd/gc`，清理未被引用的对象），但它清的是孤儿对象，
不会替你压缩正常使用量。

### 1.4 带宽与流量：语音视频中继是大头

普通聊天、发图对带宽要求很低。**真正吃流量的是 coturn 中继的通话**：

- 只有 **P2P 打洞失败、走 TURN 中继**的通话才消耗服务器流量（同一局域网或
  NAT 友好的网络会直连，不过服务器）
- 一路 1v1 视频中继按 **1-2 Mbps 双向**估；群通话（mesh，上限 4 人）成倍增长
- 一小时 1v1 视频中继 ≈ **0.5-1 GB 流量**

国内云的轻量套餐都是**按月流量包**计费（超出限速或另计费），
如果主打音视频，流量包比 CPU 内存更容易先成为瓶颈，选型时重点看这一项。
境外主机通常给几 TB 甚至不限流量，这方面压力小。

### 1.5 必须放行的端口

| 端口            | 协议    | 用途                              |
| --------------- | ------- | --------------------------------- |
| 80              | TCP     | Let's Encrypt HTTP-01 校验 + 跳转 |
| 443             | TCP     | HTTPS / WSS                       |
| 3478            | TCP+UDP | coturn 控制端口                   |
| **49160-49200** | **UDP** | **coturn 中继端口段**             |

云厂商安全组默认只开 22/80/443，**那段 UDP 一定要手动加**。
漏了的表现很有迷惑性：登录聊天发图全正常，只有跨 NAT 通话接通后黑屏无声。

### 1.6 配置档位速查

| 场景                      | 配置                  | 说明                                   |
| ------------------------- | --------------------- | -------------------------------------- |
| 试跑 / 几个人自用         | 2C 2G 40G + swap      | 构建须加 swap 或用预构建镜像；不开监控 |
| **小团队（推荐起步）**    | **2C 4G 80G**         | 可服务器上直接构建，不开监控           |
| 开可观测套件              | 2C 8G 80G             | Prometheus + Grafana + Loki 要额外内存 |
| 音视频用得多 / 几十人在线 | 4C 8G 160G + 大流量包 | 瓶颈通常是 coturn 流量而非 CPU         |

## 二、国内服务器

### 2.1 绕不开的前提：ICP 备案

**域名解析到中国大陆境内服务器并提供 Web 服务，必须先完成 ICP 备案**，否则
80/443 会被阻断。这不是可选项：

- 周期约 **15-20 个工作日**（各省管局不同），需身份证/营业执照、拍照核验
- 备案绑定「服务商 + 域名」，所以域名通常也要在同一家（或有国内资质的注册商）买
- **个人备案一般不允许做社交/通讯类服务**，元聊这种 IM 属于敏感类目，
  很可能被要求企业主体，甚至需要额外的增值电信业务许可（ICP 许可证 / EDI）
- 备案期间网站不能对外提供服务

> **如果你只是自用或小圈子测试，备案这一关往往比技术部署还麻烦。**
> 折中方案是买**香港/新加坡**节点（无需备案，延迟对大陆仍可接受），见 §2.3。

### 2.2 中国大陆（需备案）

按参考价位从低到高。国内云的**首年促销价与续费原价差异极大**，务必看清续费价：

| 服务商              | 典型配置   | 参考价位（首年促销） | 参考价位（续费/原价） | 备注                    |
| ------------------- | ---------- | -------------------- | --------------------- | ----------------------- |
| 腾讯云 轻量应用     | 2C 2G 40G  | ¥100-300 / 年        | ¥60-90 / 月           | 含月流量包，超出限速    |
| 阿里云 轻量应用     | 2C 2G 40G  | ¥100-300 / 年        | ¥60-90 / 月           | 同上；生态文档最全      |
| 华为云 / 京东云     | 2C 4G 50G  | ¥300-600 / 年        | ¥100-160 / 月         | 促销力度时好时坏        |
| 腾讯云 / 阿里云     | 2C 4G 80G  | ¥400-800 / 年        | ¥120-200 / 月         | **推荐起步档**          |
| 各家 ECS/CVM 标准型 | 4C 8G 100G | —                    | ¥300-600 / 月         | 按量/包年，比轻量贵不少 |

**优点**：大陆访问延迟低（对实时通话体验影响明显）、支付与售后方便。
**缺点**：备案门槛、流量包偏小且超出后限速、续费贵。

### 2.3 香港 / 新加坡（免备案，兼顾大陆访问）

| 服务商                    | 典型配置 | 参考价位      | 备注                          |
| ------------------------- | -------- | ------------- | ----------------------------- |
| 腾讯云 / 阿里云 轻量·香港 | 2C 2G    | ¥300-600 / 年 | 免备案，大陆延迟通常 30-80 ms |
| 阿里云 轻量·新加坡        | 2C 4G    | ¥500-900 / 年 | 延迟略高于香港                |
| 其他中小商家香港 CN2 GIA  | 2C 4G    | ¥60-200 / 月  | 线路质量参差，务必先买月付试  |

> 香港节点带宽普遍小（常见 1-30 Mbps）且流量包贵，**做音视频中继要特别留意带宽**。

## 三、境外服务器（免备案，性价比高）

按参考价位从低到高。大陆直连质量普遍不如国内/香港节点，适合用户主要在海外的场景：

| 服务商                   | 典型配置              | 参考价位       | 备注                                                            |
| ------------------------ | --------------------- | -------------- | --------------------------------------------------------------- |
| **Oracle Cloud 免费层**  | ARM 4C 24G 200G       | **￥0**        | 真·免费且配置夸张，但**长期缺货、账号易被回收**，不适合正式服务 |
| Contabo                  | 4C 8G 200G            | €6-9 / 月      | 同价位配置最高，但超售明显、性能波动大                          |
| **Hetzner**（CX22/CX32） | 2C 4G 40G / 4C 8G 80G | **€4-11 / 月** | **性价比之选**，德国/芬兰/美国机房，口碑好，需实名              |
| Vultr                    | 2C 4G 80G             | $20-24 / 月    | 机房多（含东京/首尔，对大陆较友好），按小时计费                 |
| DigitalOcean             | 2C 4G 80G             | $24 / 月       | 文档与生态最好，价格偏贵                                        |
| AWS Lightsail            | 2C 4G 80G             | $24 / 月       | 固定价，比 EC2 省心；要接 AWS 生态时选它                        |
| AWS EC2 / GCP / Azure    | 按需                  | 通常更贵       | 除非要用云厂商托管数据库等配套，自托管没必要                    |

**选型建议**：

- 预算优先、用户在海外 → **Hetzner**
- 要东亚低延迟 → **Vultr 东京/首尔** 或 香港节点
- 想白嫖试玩 → Oracle 免费层（**别放正式数据**）

## 四、域名

### 4.1 需要几个

本项目需要 **5 个子域名**（`app` / `api` / `ws` / `admin` / `storage`），
但它们都是同一个主域名下的子域，**只需要买 1 个域名**，然后加 5 条 A 记录。

### 4.2 注册商参考价（.com，按价格排序）

| 注册商                   | .com 首年     | .com 续费  | 备注                                                                           |
| ------------------------ | ------------- | ---------- | ------------------------------------------------------------------------------ |
| 腾讯云 / 阿里云          | ¥35-75        | ¥75-110    | **要在大陆备案就选这类国内注册商**                                             |
| NameSilo                 | $9-11         | $10-12     | 免费 WHOIS 隐私，界面老但便宜稳定                                              |
| Porkbun                  | $9-11         | $11-13     | 免费隐私 + 免费 SSL，体验好                                                    |
| **Cloudflare Registrar** | **$10-11**    | **$10-11** | **按成本价卖、不加价、续费不涨**，但不接受新注册转入以外的某些 TLD；无首年促销 |
| GoDaddy / Namecheap      | $1-12（促销） | $20-25     | 首年很便宜，**续费显著涨价**，注意长期成本                                     |

其他 TLD 参考：`.cn` 国内首年常见 ¥25-35（需实名）；`.xyz` / `.top` 促销可低至 ¥10 以内
但部分邮件服务商对这些后缀的信任度低。

### 4.3 选注册商的两条硬约束

1. **要备案 → 必须用国内注册商**（阿里云/腾讯云等有资质的），境外注册商的域名没法走备案流程
2. **不备案（用境外/香港服务器）→ 随便选**，此时推荐 Cloudflare Registrar
   （成本价、续费不涨价）或 Porkbun

### 4.4 DNS 解析

域名买在哪家，DNS 就可以用哪家的解析，也可以把 NS 指到 **Cloudflare 免费 DNS**
（解析快、免费、面板好用）。注意：

- 5 条记录全部解析到服务器公网 IP，**解析生效后再跑 `install.sh`**，
  否则 Let's Encrypt 的 HTTP-01 校验会失败
- 用 Cloudflare 时，**这 5 条记录建议先关掉橙色小云朵（仅 DNS，不代理）**。
  开代理会让 WebSocket、证书签发、以及 coturn 的直连出问题；
  等服务跑通了再按需逐条评估

## 五、一句话怎么选

| 你的情况                     | 建议                                                           |
| ---------------------------- | -------------------------------------------------------------- |
| 就想本地/内网跑起来看看      | 不用买，照 [DEVELOPMENT.md](../DEVELOPMENT.md) 本地起 dev 链路 |
| 自用或小圈子，怕麻烦不想备案 | 香港轻量 2C4G + 任意境外注册商域名                             |
| 用户主要在海外，预算敏感     | Hetzner CX32（4C8G）+ Cloudflare Registrar 域名                |
| 正经对大陆用户提供服务       | 国内云 2C4G 起 + 国内注册商域名 + **老实备案**（企业主体）     |
| 音视频是主打功能             | 优先加**流量包/带宽**，其次才是 CPU 内存                       |
