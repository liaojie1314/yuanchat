# 03 — 通讯录页面设计规范（Contacts Page）

> 路由: `/contacts`
> 涵盖：联系人列表 / 字母索引 / 好友申请 / 搜索添加 / 扫码 / 联系人详情 / 群组列表 / 企业通讯录
> 依赖：`DESIGN_LANGUAGE.md`

---

## 一、设计目标（Design Goals）

### 1.1 通讯录要解决的核心问题

1. **快速找到人**：2 次点击内找到目标联系人（字母索引 + 实时搜索）
2. **清楚看到状态**：一眼知道对方在不在线、签名是什么
3. **低摩擦添加好友**：元聊号、手机号、扫码、二维码图片识别均支持
4. **企业场景**：层级部门展示、角色/职位显示、批量操作

### 1.2 与竞品差异化

| 竞品痛点                                 | 元聊解法                                  |
| ---------------------------------------- | ----------------------------------------- |
| 微信通讯录分类入口杂乱                   | 功能入口精简为 3 个，语义清晰             |
| QQ 通讯录分组管理复杂                    | 默认字母排序 + 用户自建标签（非强制分组） |
| Telegram 无状态显示                      | 实时在线状态 + 自定义状态文字             |
| 多数 IM 字母索引不可用（列表短时候显示） | 始终可见，≥ 5 人时启用快跳                |
| 多数 IM 添加好友只支持 ID 搜索           | 支持手机号、邮箱、扫码、附近的人（可选）  |

## 三、通讯录面板

### 3.1 顶部栏（56px）

```
布局: flex, items-center, justify-between, px-4
"通讯录" Title Large, 600

[+] 添加联系人按钮:
  40×40px, IconButton
  点击: 弹出添加联系人 Modal / 全屏（移动）
  长按: 快捷菜单 [扫码] [搜索添加] [手机联系人]
```

### 3.2 搜索栏

```
变体: 搜索框（左侧 Search 16px 图标）
高度: 40px，radius 10px
背景: surface-container-high
margin: 8px 12px
placeholder: "搜索联系人、备注、元聊号…"

右侧: [X 清除]（有内容时）

搜索行为:
  实时搜索（防抖 200ms）
  搜索范围: 昵称、备注名、元聊号、手机号（仅自己的联系人）
  搜索时: 隐藏功能入口和字母分组，展示搜索结果

无结果提示（带 CTA）:
  "没有找到 '关键词'"
  下方: "[🔍] 在全网搜索 '关键词' 元聊用户 →"
  点击 → 进入添加联系人，预填关键词
```

### 3.3 功能入口区

```
┌──────────────────────────────────────────────────┐
│  [图标] 新的朋友              [3] >               │  有新申请时显示红点角标
│  [图标] 群聊                        >             │
│  [图标] 企业通讯录                   >             │
└──────────────────────────────────────────────────┘

每项:
  高度: 52px

  标题: Body Large, 600, on-surface

  新的朋友: UserPlus，linear-gradient(135°, #5B9BD5, #7EC8E3)
  群聊:     Users，linear-gradient(135°, #5A6D82, #7A8DA2)
  企业通讯录: Building2，linear-gradient(135°, #5B8A8A, #7BAAAA)

分隔线: 1px outline-variant，在功能入口区下方 + 上方
```

### 3.4 联系人字母分组列表

**分组标题**

```
高度: 28px
背景: surface-container
内边距: 水平 16px
字体: Label Medium, 600, on-surface-variant
粘性定位: position sticky, top 0（滚动时吸顶）
内容: "A" "B" ... "Z" "#"（数字/特殊字符）

新增: "★ 星标联系人"（若有）显示在最顶部分组
```

**联系人列表项（ContactItem）**

```
高度: 60px
内边距: 水平 16px, gap 12px

左侧: Avatar 40px (md)，带在线状态点

信息区（min-w-0，flex-1）:
  昵称（或备注名）: Body Large, 600, on-surface, truncate
  副文字（1 行）:
    有备注名时: 原昵称（灰色括号表示）
    无备注名时: 个性签名（on-surface-variant）
    企业联系人: 职位 + 部门（on-surface-variant）
    在线状态文字（自定义状态文字）优先显示

右侧（桌面）: ChevronRight 16px, on-surface-variant
右侧（移动）: 在线状态点/状态文字

激活态: primary-container 背景
悬浮态: surface-container-high 背景
```

**星标联系人（新增）**

```
点击联系人详情中的"星标" → 顶部单独分组 "★ 星标联系人"
星标: filled Star 12px, #F59E0B，右侧图标
取消星标: 从该分组移除，回到字母排序
最多: 无上限，但超过 20 个时分组折叠（默认展示 10 个）
```

### 3.5 字母索引栏（右侧）

```
显示条件: 联系人 ≥ 5 人（始终显示，增强发现性）
位置: 面板右侧边缘，垂直居中，absolute 定位
宽度: 16px

字母: Label Small, on-surface-variant
激活（当前字母）: primary 色，字号放大，scale(1.3)
点击/触摸: 滚动到对应分组（smooth scroll）

气泡指示器:
  触摸字母时，面板中央显示 64×64px 半透明气泡
  背景: inverse-surface, radius 12px
  文字: 字母，Headline Large, inverse-on-surface
  500ms 后消失

快速滑动（移动端）:
  手指不抬起时持续滑动，实时更新滚动位置 + 气泡字母
  触觉反馈: light impact 每次字母变化
```

### 3.6 联系人标签分组（新增，用户自建）

```
入口: 通讯录顶部 [≡ 标签管理] 按钮（或设置 → 通讯录 → 标签）

标签:
  用户可自建标签（如"同事" "家人" "合作方"）
  一个联系人可有多个标签

标签列表区（切换显示模式）:
  [全部] [★ 星标] [同事 5] [家人 3] [合作方 8]
  Chip 横滑，在搜索栏下方

标签列表项: 同普通列表项，顶部显示当前标签名称

标签编辑:
  长按联系人 → [设置标签]
  或联系人详情 → [标签] 行 → 多选标签 Popover
```

### 4.3 搜索添加 Tab

```
搜索框:
  placeholder: "元聊号 / 手机号 / 邮箱"
  高度: 48px，有搜索图标
  实时搜索（防抖 400ms，等待完整输入）
  清除按钮

搜索中: Spinner 替换右侧图标

搜索结果 — 用户卡片:
┌────────────────────────────────────────────────────────┐
│  [Avatar 56px]  昵称（备注名）                [操作按钮]│
│                 元聊号: Y12345678                       │
│                 个性签名: 人生苦短，且行且珍惜…          │
│                 共同好友: 李四、王五 共认识              │

  已是好友:   [发消息] Button Outlined sm，跳转会话
  未添加:     [+ 加好友] Button Filled sm，brand-gradient
  已发申请:   [等待验证] Button Text，disabled 灰色
  已被拉黑:   不显示任何结果（后端不返回）

无结果（输入完整后 0 结果）:
  Search 48px icon
  "未找到 '搜索词'"
  "可以尝试扫描对方的元聊二维码添加"
```

### 4.4 扫码添加 Tab

```
桌面（相机权限）:
  扫码区: 280×280px，radius 12px
  4 角 L 型扫描框（品牌色，40×40px，宽 3px）
  扫描线: 3px，primary/60%，从上到下循环 2s
  右下: [从相册选取] Button Text，从本地图片识别二维码

无相机权限:
  ShieldAlert 48px, on-surface-variant
  "需要相机权限才能扫码"
  [去开启权限] Button Outlined

移动端:
  全屏相机预览
  4 角扫描框
  [从相册] 底部 Button

识别成功:
  短震动 + 绿色扫描框短闪 → 弹出识别结果：
    元聊用户: 显示用户卡片（同搜索结果）
    群聊链接: 显示群聊信息 + [加入群聊]
    好友链接: 显示用户卡片
    URL: 显示链接预览 + [打开] [复制]
    无法识别: Toast "无法识别此二维码"
```

### 4.5 手机联系人 Tab（仅移动端）

```

  Contacts 64px icon + 说明文字

  底部: "未显示的联系人尚未注册元聊"

  顶部 Banner: "你的 5 位手机联系人还未注册元聊"
  [一键邀请] Button Outlined → 系统分享"我在用元聊，邀请你加入…"
```

### 4.6 附近的人 Tab（可选，需位置权限）

```
权限请求（同手机联系人权限流程）

用户列表（附近 1km 内开启了"附近可见"的用户）:
  列表项同搜索结果
  显示大概距离: "约 200 米" Label Small, on-surface-variant

隐私说明:
  "附近的人仅在你主动开启时才会显示"
  "任何时候均可在设置 → 隐私中关闭"

刷新: 每 30s 自动刷新，手动下拉刷新
```


### 6.3 横幅区渐变规格

```
高度: 120px（桌面）/ 140px（移动）

背景生成规则（优先级递减）:
  A. 用户自定义背景图（裁剪并模糊处理）
  B. 头像主色提取（Dominant Color API）
     linear-gradient(135°, dominantColor/80% 0%, dominantColor/30% 100%)
  C. 基于用户 ID 哈希选取品牌调色盘
  D. 兜底: linear-gradient(135°, #5B9BD5 0%, #7EC8E3 100%)

过渡到内容区:
  底部 20px: mask-image: linear-gradient(to bottom, black, transparent)
  下方 surface 背景接续，制造无缝衔接感

Avatar 出血:
  position: absolute
```
