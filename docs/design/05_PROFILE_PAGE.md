# 05 — 个人资料页面设计规范（Profile Page）

> 涵盖：我的个人资料 / 编辑资料 / 我的二维码 / 他人资料 / 在线状态 / 动态/朋友圈（预留）
> 依赖：`00_DESIGN_LANGUAGE.md`

---

## 一、设计目标（Design Goals）

### 1.1 个人资料页要解决的三件事

1. **展示完整身份**：头像、昵称、签名、在线状态、共同社交关系一屏可见
2. **低摩擦操作**：从资料页直接发消息/通话，不需要先找到会话
3. **信任建立**：对于陌生人，展示共同好友/群聊，降低添加门槛

### 1.2 与竞品差异化

| 竞品痛点                         | 元聊解法                                |
| -------------------------------- | --------------------------------------- |
| 微信个人资料信息密度低，大量空白 | Banner + 卡片信息合理填充，增加社交背景 |
| QQ 资料页风格与应用主风格割裂    | 完全使用设计系统组件，风格一致          |
| 多数 IM 不支持自定义状态文字     | 支持 emoji + 文字组合（最多 60 字符）   |
| 他人资料不显示共同关系           | 共同好友、共同群聊显著展示，降低陌生感  |

## 三、个人横幅区（Profile Banner）规格

```
高度:
  桌面: 120px
  移动: 140px
  编辑 Modal: 120px

背景生成（优先级递减）:
  A. 用户自定义背景图（图片 URL，存储到云端）
  B. 用户选择的纯色或渐变（colorScheme 字段）
  C. 基于头像 dominant color 生成渐变
     linear-gradient(135°, dominantColor/80% 0%, dominantColor/30% 100%)
  D. 基于用户 ID 哈希的品牌调色盘
  E. 兜底: linear-gradient(135°, #5B9BD5 0%, #7EC8E3 100%)

Avatar 出血定位:
  position: absolute
  bottom: -48px（Avatar 半径 48px）
  left: 50%（桌面居中）/ 20px（移动端左对齐）
  transform: translateX(-50%) / none

  Avatar 外圈（浮出感）: 4px solid surface
  暗色模式: 4px solid surface（surface 即暗色背景，自然融合）

过渡到内容:
  底部 24px: mask-image: linear-gradient(black 70%, transparent)
  + 下方 surface 背景接续（无明显分界线）

自定义背景触发:
  桌面: hover 横幅 → 显示覆盖层 "Camera 图标 + 更换背景" 白字
  移动: 点击横幅 → Bottom Sheet
    [从相册选取背景图]
    [选择纯色 / 渐变]
    [恢复默认]

背景图裁剪:
  object-fit: cover, 横幅宽×高比 (桌面~1200:120, 移动~390:140)
  上传时在客户端预裁剪，减少上传体积
  高斯模糊（可选，Blur 强度 4px，确保文字可读）
```

## 四、在线状态与自定义状态（Online Status）

### 4.1 状态类型

| 状态           | 颜色                  | 说明                         |
| -------------- | --------------------- | ---------------------------- |
| 在线 Online    | `#22C55E`             | 活跃使用中                   |
| 离开 Away      | `#F59E0B`             | 超过 10 分钟无操作自动切换   |
| 忙碌 Busy      | `#EF4444`             | 手动设置，不接收通知声音     |
| 请勿打扰 DND   | `#B45309`             | 手动设置，仅显示角标不弹通知 |
| 离线 Offline   | `#9CA3AF`             | 退出登录或 App 后台          |
| 隐身 Invisible | `#9CA3AF`（实际在线） | 显示离线但实际接收消息       |

### 4.2 自定义状态文字（Custom Status）

```
入口: 个人资料页昵称下方状态点 → 点击弹出状态 Picker

在线状态切换（单独的另一个选项）:
  直接显示: ● 在线 / ● 离开 / ● 忙碌 / ● 请勿打扰 / ● 隐身
  Radio 选择，立即生效
```

## 十一、状态规范

### 11.1 加载状态（骨架屏）

```
横幅: 全宽矩形灰色块（高度 120/140px）
Avatar: 圆形灰块（96px），出血定位
昵称: 120×20px 灰条
元聊号: 80×14px 灰条
签名: 200×14px 灰条
信息行: 3 行，各 240×14px 灰条（宽度随机 180-260px）
shimmer 动画 1.5s 循环
```

### 11.2 错误状态

```
用户不存在:
  UserX 48px, on-surface-variant
  "找不到该用户"  Body Large
  "该账号不存在或已注销"  Body Medium, on-surface-variant
  [返回]  Button Outlined

被拉黑:
  Shield 48px, on-surface-variant
  "无法查看该用户的资料"  Body Large
  [返回]  Button Outlined

网络错误:
  AlertCircle 48px + "加载失败" + [重试]
```

### 11.3 空字段处理

```
性别 / 生日 / 地区 未填写: 显示 "未设置"（on-surface-variant/50%）而非空行
个性签名未填写: 显示 "这个人很懒，还没有个性签名"（系统默认文字）
在线状态文字无: 隐藏该行（不占空间）
```
