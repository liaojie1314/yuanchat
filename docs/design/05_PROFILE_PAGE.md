## 二、个人横幅区（Profile Banner）规格

```
高度:
  桌面: 120px
  移动: 140px

背景渐变生成规则:
  方案A（有头像）: 提取头像 dominantColor，生成 linear-gradient(135deg, dominantColor/80%, dominantColor/30%)
  方案B（无头像/系统头像）: 基于用户 ID 哈希选取品牌调色盘中的颜色
  兜底: linear-gradient(135deg, #5B9BD5 0%, #7EC8E3 100%)

  示例渐变:
    蓝色系: linear-gradient(135deg, rgba(91,155,213,0.8) 0%, rgba(168,207,255,0.5) 100%)
    绿色系: linear-gradient(135deg, rgba(56,106,32,0.8) 0%, rgba(157,214,123,0.5) 100%)

Avatar 定位（出血效果）:
  position: absolute
  bottom: -48px (Avatar 半径 + 偏移)
  left: 50% (桌面居中) / 20px (移动左对齐)
  transform: translateX(-50%) / none

  Avatar 外边框: 4px solid surface（与背景融合，制造浮出感）

顶栏操作区 (绝对定位在 Banner 右上):
  [编辑] Button Small Outlined（白色边框/文字，透明背景）
  [⋮]  更多菜单按钮（白色图标，透明背景）
  可选: [相机图标] 悬浮在 Banner 上方（修改背景图）

Banner 内嵌编辑提示（悬浮时显示）:
  覆盖层: rgba(0,0,0,0.3)
  文字: Camera 图标 + "更换背景"，白色，Body Medium
  仅桌面端悬浮触发；移动端点击即触发 picker
```

- 个人资料页顶部 [编辑] 按钮

### 3.4 头像编辑流程

```
1. 点击头像区
2. 底部 ActionSheet（移动）/ 弹出菜单（桌面）:
   - 从相册选择（图库访问权限）
   - 拍照（摄像头权限，仅移动端）
   - 查看原图
   - 删除头像（恢复为彩色字母头像）

3. 选择图片后打开裁剪界面:
   ┌──────────────────────────────────────┐
   │  裁剪头像                   [×]      │
   │  ┌────────────────────────────────┐  │
   │  │                                │  │
   │  │       [图片裁剪区]              │  │
   │  │    圆形蒙版覆盖在图片上         │  │
   │  │    图片可拖动、缩放             │  │
   │  │                                │  │
   │  └────────────────────────────────┘  │
   │  [-]   缩放滑块   [+]               │
   │                                      │
   │  [重新选择]            [确认使用]    │
   └──────────────────────────────────────┘

4. 保存时显示上传进度（圆形进度条覆盖头像）
5. 上传成功后即时更新预览
```

### 4.3 二维码卡片规格

```
卡片:
  背景: #FFFFFF（始终白色，不受主题影响，保证扫码可用）
  圆角: 20px
  内边距: 24px
  阴影: elevation-3

二维码:
  尺寸: 240×240px
  错误纠正级别: M（容纳中心 Logo）
  中心 Logo: 元聊 Logo 40×40px, 白色圆角方形背景，缩小版 MessageCircle 图标
  边框: 4px white 内边距（防二维码边缘被遮挡）

  Avatar: 64px，位于二维码下方 16px
  昵称: Title Medium 600
  元聊号: Label Medium, #6B7280（固定灰色，不随主题变，保证打印/截图可读）

操作按钮行:
  [保存图片] Outlined 小号，Download 图标
    功能: 截取卡片区域为图片保存到设备
  [分享] Outlined 小号，Share2 图标
    功能: 系统分享（移动端 Web Share API）
  [复制链接] Text 小号，Link 图标
    功能: 复制元聊个人链接（yuanchat://user/Y12345678）
```

```

  横幅区: 全宽矩形灰色块
  头像: 圆形灰色块，出血定位
  昵称: 120×20px 灰色条
  元聊号: 80×14px 灰色条
  各信息行: 240×14px 灰色条

  shimmer 动画: 1.5s 循环

  头像区: AlertCircle 48px, error 色
```
