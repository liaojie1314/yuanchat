# 01 — 认证页面设计规范

> 涵盖：登录 / 注册 / 忘记密码
> 背景：Aurora 极光风格，三层装饰（光球 + 微尘网格 + 流光扫描）

---

## 一、设计原则

- **一致的沉浸感**：三个页面共享完全相同的背景装饰层，用户在跳转时背景不闪烁
- **逐步披露**：注册和找回密码拆分为步骤流，每步只问最少信息
- **即时反馈**：每个输入框失焦时校验，错误就地提示，不等到提交
- **快速聚焦**：进入页面自动聚焦第一个输入框

### 4.6 安全提示

重置成功后需注意的 UX 细节：

- 重置后使原登录 token 全部失效（已在其他设备登录的会话踢下线）
- 系统消息推送："你的账号密码已被修改，请确认是否为本人操作"
- 重置密码表单不允许与近3次使用的密码相同

## 六、页面跳转关系

```
/login
  ├── [立即注册] ──────────────────► /register
  ├── [忘记密码] ──────────────────► /forgot-password
  └── [登录成功] ──────────────────► /chat (redirect, replace history)

/register
  ├── [步骤1完成] ─────────────────► /register/step2 (或同页步骤切换)
  ├── [注册成功] ──────────────────► /chat
  └── [已有账号] ──────────────────► /login

/forgot-password
```
