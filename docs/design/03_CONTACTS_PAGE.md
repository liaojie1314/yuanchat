> 路由: `/contacts`
> 涵盖：联系人列表 / 好友申请 / 搜索添加 / 联系人详情

## 二、通讯录面板

### 2.1 顶部栏

```
布局: flex, items-center, justify-between
高度: 56px
内边距: 水平 16px

左侧: "通讯录" Title Large, 600, on-surface
右侧:
  [+] 添加联系人图标按钮
    点击: 弹出添加好友 Modal
```

### 2.2 搜索栏

```
输入框规格:
  变体: 搜索框（左侧 Search 16px 图标）
  高度: 40px
  圆角: xl (12px)
  背景: surface-container-high
  margin: 8px 12px
  placeholder: "搜索联系人"

搜索行为:
  实时搜索（防抖 200ms）
  搜索内容: 昵称、备注名、元聊号
  搜索时: 隐藏功能入口和字母分组，展示搜索结果
  无结果: 显示 "未找到联系人，在全网搜索 '[关键词]' →"（链接，点击进入添加好友）
```

### 2.3 功能入口区

```
┌────────────────────────────────────────┐
│  [新的朋友 🙋]           [1] →         │
│  [群聊 👥]                    →        │
│  [企业通讯录 🏢]              →        │
└────────────────────────────────────────┘

每项:
  高度: 52px
  布局: flex, items-center, gap 12px, px-4
  图标容器: 40×40px，圆角 12px，品牌色渐变背景，白色图标（20px）
  标题: Body Large, 600, on-surface
  右侧: 未读申请角标（仅"新的朋友"有）+ ChevronRight

图标/颜色:
  新的朋友: UserPlus，primary 渐变
  群聊:     Users，secondary 渐变 (#5A6D82 → #7A8DA2)
  企业通讯录: Building2，tertiary 渐变 (#5B8A8A → #7BAAAA)

分隔线: 1px outline-variant，在功能入口区下方
```

### 2.4 联系人字母分组列表

```
字母分组标题:
  高度: 28px
  背景: surface-container (#E5ECF6 / #1A2028)
  内边距: 水平 16px
  字体: Label Medium, 600, on-surface-variant
  内容: "A", "B", ... "Z", "#"（其他字符）

联系人列表项:
  高度: 60px
  内边距: 水平 16px, gap 12px

  左侧: Avatar 40px (md)
  中间:
    昵称: Body Large, 600, on-surface
    状态/签名: Label Medium, on-surface-variant, 1行截断（显示备注名或签名）
  右侧: ChevronRight（桌面）/ 无（移动）

  激活态: primary-container 背景
  悬浮态: surface-container-high 背景

字母索引栏（右侧）:
  仅在联系人≥20人时显示
  位置: 右侧边缘，垂直居中
  宽度: 16px
  字母: Label Small, on-surface-variant
  点击/触摸: 滚动到对应分组，高亮放大当前字母
  气泡指示: 点击时显示居中大字母提示气泡（64×64px, inverse-surface 背景）
```

### 2.5 联系人分组（企业版）

```
分组可折叠:
  分组标题: [▶/▼] 部门名称 (N人)  [...]
  展开: 显示成员列表
  折叠: 隐藏成员列表（动画 200ms）

  成员状态点:
    在线: 绿色 (#22C55E)
    忙碌: 黄色 (#EAB308)
    请勿打扰: 红色 (#EF4444)
    离开: 橙色 (#F97316)
    离线: 灰色 (#9CA3AF)
```

## 三、添加联系人（Add Contact Modal）

### 3.1 触发入口

- 通讯录顶部 `+` 按钮
- 主导航搜索全局搜索后无结果时
- 接收好友申请后

### 3.2 布局

```
Modal 布局（桌面）/ 全屏（移动）:

┌──────────────────────────────────────────────────────┐
│  添加联系人                                   [×]     │
├──────────────────────────────────────────────────────┤
│                                                      │
│  [方式 Tab]                                          │
│  [搜索添加]  [扫码添加]  [手机联系人]                 │
│                                                      │
├──────────────────────────────────────────────────────┤
│                                                      │
│  — 搜索添加 —                                       │
│                                                      │
│  ┌──────────────────────────────────────────────┐    │
│  │  🔍  元聊号 / 手机号搜索                       │    │
│  └──────────────────────────────────────────────┘    │
│                                                      │
│  [搜索结果 — 用户卡片]                               │
│  ┌──────────────────────────────────────────────┐    │
│  │  [Avatar 48px]  张三丰              [加好友]  │    │
│  │                元聊号: Y12345678              │    │
│  │                个性签名: 人生苦短…             │    │
│  └──────────────────────────────────────────────┘    │
│                                                      │
└──────────────────────────────────────────────────────┘
```

### 3.3 搜索结果用户卡片

```
容器: surface-container，圆角 16px, elevation-1
内边距: 16px
布局: flex, items-center, gap 12px

头像: 56px
基本信息:
  昵称: Title Medium, 600, on-surface
  元聊号: Label Medium, on-surface-variant
  签名: Body Small, on-surface-variant, 1行截断

操作按钮:
  已是好友: [发消息] Button Outlined 小号
  未添加:   [加好友] Button Filled 小号（brand-gradient）
  已申请:   [等待验证] Button Text，disabled 样式
  被对方拉黑: 不显示任何信息（搜索无结果）

"加好友" 点击后:
  弹出申请附言输入框（200字限制）
  "我是 [当前用户昵称]，来自[来源]" 默认文案
  [发送申请] 按钮
```

### 3.4 扫码添加

```
扫码区域:
  尺寸: 280×280px（桌面）/ 屏幕宽度-64px（移动）
  样式: 圆角 12px，4角有品牌色扫描框角标
  扫描线: 从上到下循环移动的 primary/60% 横线
  相机权限提示: 若无权限，显示 ShieldAlert 图标 + 引导开启

识别后:
  解析结果是元聊用户: 显示用户卡片
  解析结果是群聊链接: 显示群聊信息 + 加入群聊
  其他: 显示 URL 或错误
```

```

若无主色: 使用 primary 色 (#5B9BD5)
高度: 120px
过渡到内容: 底部使用 mask-image 渐变到 surface 背景色
```

### 5.3 修改备注弹窗

```
小型 Dialog:
  标题: "修改备注名"
  输入框: "备注名" Input，maxLength 20
  清除按钮: ×（仅有内容时）
  字数计数: 右对齐，Label Small
  操作: [取消] [保存]
```

## 七、搜索联系人结果

```
搜索结果优先级:
  1. 备注名完全匹配
  2. 昵称完全匹配
  3. 元聊号完全匹配
  4. 昵称/备注名包含
  5. 手机号（仅限已添加联系人）

结果项（和联系人列表项相同样式）:
  关键词高亮: 匹配部分黄色背景 (#FEF08A / #854D0E)，黑色文字

"在全网搜索":
  搜索框下方固定显示
  "[🔍] 搜索 '张三' 的元聊用户"
  点击 → 进入添加联系人流程，预填搜索词
```
