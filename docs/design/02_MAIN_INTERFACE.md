
### 4.3 消息列表区

#### 时间分隔符

```
外观: 水平线居中，文字叠在上面
    ── 昨天 ── / ── 2026-06-29 ── / ── 14:30 ──
字体: Label Medium, on-surface-variant
颜色: outline-variant 线条
内边距: 上下 16px
时机: 相邻两条消息间隔超过 5 分钟时插入
```

#### 消息条目（MessageItem）

```
布局规则:
  发送方 (isSelf=true):  flex-row-reverse, 头像在右
  接收方 (isSelf=false): flex-row, 头像在左

布局: flex, gap 8px, align-start

[Avatar 区] 40px:
  仅第一条连续消息显示头像（后续连续消息 Avatar 区占位但透明）
  连续消息判断: 同一发送人，3分钟内

[气泡区]:
  最大宽度: 70%
  包含:
    - 发送人名称（群聊中接收方消息的首条显示）: Label Medium, primary 色
    - 消息内容（见消息类型）
    - 底部状态行: 时间 + 已读状态

已读状态图标 (发送方):
  Clock: 发送中
  Check: 已送达
  CheckCheck primary色: 已读
  位置: 气泡右下角，Label Small, on-surface-variant

消息工具栏 (悬浮/长按显示):
  位置: 气泡上方，elevation-3 弹出卡片
  内容: [表情反应快选 5个] [回复] [转发] [复制] [更多…]
  高度: 40px
  背景: surface-container-highest，圆角 full
```

#### 消息类型详细规格

**文本消息**

```
内边距: 水平 16px, 垂直 10px
字体: Body Large (1rem/14px)
行高: 1.5
链接: primary 色，悬浮下划线
Emoji: 保留系统渲染
纯 Emoji 消息: 字号放大 2rem，无背景气泡
代码内联: monospace, surface-container-high 背景, 圆角 4px, 内边距 2px 4px
```

**图片消息**

```
容器: 圆角 12px，overflow hidden
尺寸: 最大 240×240px，等比缩放
加载中: 骨架屏（尺寸已知时）/ 进度条
已加载: 图片
点击: 全屏图片浏览器（darkened overlay, 左右切换，下载按钮）
```

**文件消息**

```
布局: flex, items-center, gap 12px
文件图标: 40×48px, 圆角 8px, 类型颜色背景（PDF红/Word蓝/Excel绿/其他灰）
文件信息:
  文件名: Body Large, 600, on-surface, 最多2行截断
  文件大小: Label Medium, on-surface-variant
下载按钮: Download 图标，16px，primary 色
下载进度: 进度条替换底部文字
```

**语音消息**

```
布局: flex, items-center, gap 8px
播放按钮: Play/Pause 圆形按钮 36px，primary 填充
波形图: 60×24px，竖条表示振幅，播放进度以 primary 色填充
时长: Label Medium, on-surface-variant
播放状态: 进度动画，自动停止
```

**引用回复消息**

```
气泡顶部额外区域:
  左侧竖条: 3px, primary 色
  引用区: surface-container，圆角 4px，内边距 6px 8px
  引用发送人: Label Medium, primary 色
  引用内容: Body Small, on-surface-variant, 最多2行
  分隔: 4px gap 后接正文内容
```

**系统消息（System Message）**

```
样式: 居中，无头像无气泡
字体: Label Medium, on-surface-variant
背景: 无（纯文字）
内容: "对方已加入元聊" / "xxx 已退出群聊" / "会话已开启"
内边距: 上下 8px
```
