## 四、设置项交互组件规格汇总

### 4.1 Toggle Switch（开关）

```
尺寸: 宽 44px, 高 26px, 圆角 full
轨道:
  开: primary (#5B9BD5)，过渡 200ms
  关: outline (#727883)
滑块: 22×22px 圆形，white，elevation-1
  开: 右对齐 (transform: translateX(18px))
  关: 左对齐 (transform: translateX(2px))
动画: 200ms standard

disabled 态: opacity 40%
```

### 4.2 Radio 单选（权限等选择）

```
尺寸: 20×20px 圆形边框 2px
默认: outline-variant 边框，transparent 背景
选中: primary 边框 + 内部 10px 圆形 primary 填充
聚焦: 外部 3px primary/30% 环

选项文字: Body Large, on-surface
右侧（可选）: 描述文字 Body Medium, on-surface-variant
```

### 4.3 Checkbox 复选框

```
尺寸: 18×18px, 圆角 4px
默认: outline-variant 边框 2px，transparent
选中: primary 背景，白色 Check 图标（12px）
过渡: 150ms

关联文字: 同行，Body Medium, on-surface
```

### 4.4 设置行完整规格

```
标准设置行（高度 52px）:
  内边距: 水平 16px
  布局: flex, items-center, justify-between

  左侧:
    图标（可选，20px, on-surface-variant）
    标题（Body Large, on-surface）
    标题下（可选，Body Small, on-surface-variant）

  右侧:
    当前值（Body Medium, on-surface-variant）
    ChevronRight（16px, on-surface-variant） 或
    Toggle Switch 或
    文字操作（primary 色 Link 样式）

行间分隔线:
  高度: 1px
  颜色: outline-variant
  起始: 左侧图标右边缘（有图标）或 16px（无图标）
  最后一行不显示
```
