# v0.4.0 实施计划：收藏 + 管理后台

> **状态：outline（milestone spec）**
> 详细 TDD 步骤在 v0.3 完成后展开。

**Goal:** 上线消息收藏（我的收藏页）；把 GORM AutoMigrate 迁到版本化迁移；构建独立管理后台（用户/会话/审计/内容审核）；补齐 ja/ko i18n。

**Architecture:** admin 独立 sub-app `apps/admin/`（React + Vite，与 `packages/shared` 共享 store/api）；后端 `POST /admin/*` 全过 admin middleware（`role=admin` 字段+审计日志）；迁移工具用 `pressly/goose`；审核队列走消息 flag 字段。

**Tech Stack:** Go 1.25 + `pressly/goose`；React 19 + Vite；`@yuanchat/shared` + `@yuanchat/ui` 复用；PostgreSQL 16。

## Global Constraints（继承）

- 分支 `feature/v0.4-favorites-admin`
- 新增：admin 端点全部审计（`admin_action_logs` 表），管理员操作必留记录
- admin 前端独立部署（`admin.yuanchat.tld`），不打包进 web/desktop
