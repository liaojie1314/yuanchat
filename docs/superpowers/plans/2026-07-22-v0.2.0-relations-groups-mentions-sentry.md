# v0.2.0 实施计划：关系管理 + 群管进阶 + @/引用/转发 + Sentry

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 v0.1.0 IM MVP 基础上补齐好友删除/黑名单、群管理进阶（管理员任命/免除/转让）、消息 @提及/引用回复/转发、Sentry 前端错误监控四大能力，构成 v0.2.0 里程碑。

**Architecture:** 全部沿 v0.1 已建骨架扩展——REST 端点挂 `server/internal/handler`、业务在 `service`（复用 `convRepo.DB().Transaction`）、WS 帧在 `ws/protocol.go` 加类型 + `handler.go` buildContent 分发、前端 `chatSocket.ServerFrames` + `useChatBootstrap.wireSocket` 两端同步、UI 状态走 Zustand store。Sentry 在 `packages/shared/observability/sentry.ts` 单点初始化，Web / Desktop / Android 三端 `main.tsx` 注入 DSN，CI source map 上传走 `@sentry/vite-plugin`。

**Tech Stack:** Go 1.25 / Gin / GORM / gorilla/websocket；React 19 / Zustand v5 / lucide-react / react-i18next；@sentry/react + @sentry/vite-plugin；vitest + go test。
