# v0.5.0 实施计划：分布式 Presence + 桌面代码签名 + 性能收尾

> **状态：outline（milestone spec）**
> 详细 TDD 步骤在 v0.4 完成后展开。

**Goal:** 支持多实例后端部署（Presence 走 Redis Pub/Sub）；macOS/Windows 桌面代码签名 + 公证；补齐 C2 图片懒加载、C4 WS 心跳自适应、B4 结构化日志。

**Architecture:** Presence Hub 抽象出 `PresenceBackend` 接口，`RedisPubSub` 实现替换单实例 `LocalMap`；macOS 走 Apple Developer ID + notarytool；Windows 走 EV/OV 证书 + signtool；日志层升级为 zap production config。

**Tech Stack:** Go 1.25 + Redis 7；Apple Developer 证书；EV/OV 代码签名证书；zap 结构化日志；Vite `intersectionObserver`。

## Global Constraints（继承）

- 分支 `feature/v0.5-distributed-signing`
- 新增：签名密钥严禁进仓库，走 GitHub Encrypted Secrets；本地打包保持 unsigned 兼容
- Presence backend 切换后原逻辑接口零变化（`hub.OnlineFilter` 签名不变）

## 里程碑批次

### 批次 1（B5）：Presence 分布式（1 周）

**改动关键文件：**

- `server/internal/ws/hub.go`（抽 `PresenceBackend` interface）
- `server/internal/ws/presence_local.go`（提取现有 map 实现）
- `server/internal/ws/presence_redis.go`（新增）
- `server/config/config.yaml`（`presence.backend: local|redis` + `presence.redis.channel`）
- `server/cmd/server/main.go`（依赖注入 backend）

**关键行为：**

- Redis channel `presence:events`；消息格式 `{userId, online, at, hostId}`
- Register/Unregister 时本地写状态 + 发布事件；订阅者收到事件同步本地 mirror
- 全局在线判定：`localOnline OR mirrorOnline`

**集成测试：**

- `presence_integration_test.go` 起两个 hub 实例（in-process，共享一个 Redis）
- 实例 A 上的 Alice 上线 → 实例 B 上的 Bob（Alice 好友）收到 `presence` WS 帧

**依赖：**

- 无新增 go module；已有 `go-redis/v9`

**验收：**

- 单实例回归：`backend=local` 行为与 v0.4 一致
- 双实例集成：跨实例 presence 无缝

### 批次 2（D1）：桌面代码签名 + 公证（1 周）

**改动关键文件：**

- `.github/workflows/release.yml`（macOS + Windows 双端签名启用）
- `apps/desktop/src-tauri/tauri.conf.json`（`bundle.macOS.signingIdentity` + `bundle.windows.certificate`）
- `docs/RELEASE.md`（申请流程 + secret 名 + 出错排查）

**macOS：**

- Apple Developer ID Application 证书 → export .p12 → base64 → `APPLE_CERTIFICATE` secret
- `APPLE_CERTIFICATE_PASSWORD` / `APPLE_SIGNING_IDENTITY` / `APPLE_ID` / `APPLE_PASSWORD` / `APPLE_TEAM_ID` 全部 secret
- `notarytool submit ... --wait` 公证；成功后 `stapler staple` 装订

**Windows：**

- OV/EV 证书 → `WINDOWS_CERTIFICATE`（base64）+ `WINDOWS_CERTIFICATE_PASSWORD` secret
- Tauri build 内自动 signtool（`bundle.windows.signCommand`）
- 目标：装包无「无法验证发布者」/「SmartScreen」警告（EV 需 SmartScreen 信誉积累）

**用户 action items（release 前）：**

- 购买 Apple Developer（$99/y）
- 购买 Windows OV cert（约 $200/y）或 EV cert（约 $400/y）
- 完成 identity 验证

**验收：**

- 干净 macOS Sonoma → 双击 dmg 无警告 → app 无隔离标记
- 干净 Windows 11 → 双击 msi 无 SmartScreen 拦截（OV 首次可能有，EV 无）

### 批次 3（C2）：图片消息懒加载 + 缩略图（3 天）

**改动关键文件：**

- `server/internal/model/message.go`（`Content.Image` 加 `Width int; Height int`）
- `server/internal/handler/message.go`（Create 时接收 `imageWidth/imageHeight`）
- `packages/shared/src/api/files.ts`（上传前 canvas 读 naturalWidth/Height 传后端）
- `packages/ui/src/ImageBubble.tsx`（`IntersectionObserver` 触发 presign + `aspect-ratio: w/h` 骨架占位）
- `packages/shared/src/store/messageStore.ts`（图片预签名 URL 缓存改为 lazy fetch）

**验收：**

- 打开 5000 条图片消息的会话 → network 面板无一次批量 presign
- 滚动到图片时才 presign + 加载
- 布局无 CLS（skeleton 保持宽高比）

### 批次 4（C4）：WebSocket 心跳自适应（2 天）

**改动关键文件：**

- `packages/shared/src/store/chatSocket.ts`（心跳间隔状态机 + `visibilitychange` + `navigator.getBattery`）
- `server/internal/ws/handler.go`（`pongDeadline` 调至 max(300s, 客户端心跳\*2)，最长兼容后台模式）

**心跳表：**
| 状态 | 间隔 |
| --- | --- |
| 前台 + 电池 > 20% | 30 s |
| 前台 + 电池 ≤ 20% | 60 s |
| 后台 | 120 s |
| 后台 + 电池 ≤ 20% | 300 s |

**重连：**

- 指数退避 1s → 2s → 4s → 8s → 16s → 30s（cap）
- 网络恢复事件（`online`）立即重连

**验收：**

- Android 息屏 5 min → 前台 → 重连 < 2s + 消息不丢
- 桌面前台 → tcpdump 抓包每 30s 一个 ping

### 批次 5（B4）：结构化日志聚合（2 天）

**改动关键文件：**

- `server/internal/log/log.go`（zap production config；JSON encoder + level filter）
- `server/internal/middleware/request_id.go`（生成 X-Request-ID + 塞 context）
- `deploy/logging.yml`（vector + loki + grafana docker-compose）
- `docs/observability/logging.md`

**关键字段：**

- 每条日志：`ts, level, msg, req_id, user_id, method, path, status, latency_ms`
- panic → `logger.Panic` + 堆栈 + 请求上下文

**验收：**

- 生产 build 输出 JSON 一行一条
- 本地 `docker compose -f deploy/logging.yml up` → grafana 查询 `{app="yuanchat"} |= "error"` 返回
