# v1.0.0 实施计划：iOS + PWA/Web Push + 端到端加密 + 生产部署

> **状态：outline（milestone spec）**
> 详细 TDD 步骤在 v0.5 完成后展开；D4 E2EE 是最大工程，可能独立拆为 v0.9.x 预览分支。

**Goal:** iOS ipa 出包 + TestFlight 分发；PWA 离线可用 + Web Push；单聊端到端加密（Signal Protocol）；生产部署编排（docker-compose.prod + helm chart）。

**Architecture:** iOS 走 tauri 2 + Xcode + Fastlane；PWA 走 Workbox + VAPID Web Push；E2EE 用 libsignal-client（Double Ratchet + X3DH）；生产部署一键 stack（Go/pg/redis/minio/nginx/prom/grafana/loki）。

**Tech Stack:** Tauri 2 iOS；Workbox / Web Push API；`@matrix-org/olm` OR `@signalapp/libsignal-client`；docker-compose + Helm chart。

## Global Constraints（继承）

- 分支 `feature/v1.0-ios-pwa-e2ee`（E2EE 部分可能拆 `feature/v0.9-e2ee-preview`）
- E2EE：服务器端严禁存明文；密钥备份走用户 PIN 加密的 blob（服务器不知道 PIN）
- 版本号进入 `1.x`：一次 major bump，签名的向后兼容承诺开始生效

### 批次 2（D3）：PWA + Web Push（1 周）

**新增文件：**

- `apps/web/public/manifest.webmanifest`（icons/screenshots/shortcuts）
- `apps/web/src/sw/service-worker.ts`（Workbox）
- `apps/web/vite.config.ts`（`vite-plugin-pwa`）
- `packages/shared/src/push/webPush.ts`（VAPID subscribe）
- `server/internal/handler/push.go`（`POST /push/subscribe` 存 subscription）
- `server/internal/service/push_service.go`（消息推送时读 subscription + `webpush.SendNotification`）

**依赖：**

- `pnpm add -D vite-plugin-pwa workbox-window`
- `pnpm add web-push`
- `go get github.com/SherClockHolmes/webpush-go`

**关键行为：**

- Service Worker：precache app shell（登录页 + 静态资源）+ runtime cache 头像/GET API
- Web Push：`Notification.requestPermission()` → `pushManager.subscribe(VAPID)` → 后端存 subscription
- 消息到达：后端并行推 WS 帧 + Web Push（浏览器未打开时才用后者，客户端 focus 判定）

**验收：**

- Chrome desktop / Android Chrome 安装 PWA → 添加到主屏
- 断网打开 → app shell 显示 + 提示离线
- 对方发消息 → 桌面通知弹出（浏览器关闭状态）

### 批次 3（D4）：端到端加密（3-4 周）

**架构概览：**

- **协议**：X3DH 建立初始密钥；Double Ratchet 维护会话密钥；每消息一次密钥旋转
- **密钥存储**：客户端本地 IndexedDB（web）/ SQLite（Tauri）；密钥导出为 PIN 加密 blob 上传服务器备份
- **服务器职责**：只中转密文；预共享密钥 bundle（identity + prekey + one-time key）分发
- **群聊**：v1.0 只做单聊；群聊 E2EE 走 Megolm（v1.1 再加）

**新增文件（前端）：**

- `packages/shared/src/crypto/e2ee.ts`（初始化 + 密钥管理）
- `packages/shared/src/crypto/session.ts`（Double Ratchet 封装）
- `packages/shared/src/crypto/keyBackup.ts`（PIN 加密 + 上传）
- `packages/ui/src/E2EEIndicator.tsx`（会话头锁头图标）
- `packages/ui/src/KeyFingerprintPage.tsx`（指纹对比 UI）
- `packages/ui/src/RecoveryFlowPage.tsx`（换设备恢复流程）

**新增文件（后端）：**

- `server/internal/model/{prekey,identity_key,key_backup}.go`
- `server/internal/handler/e2ee.go`（prekey bundle 分发 + 备份 blob CRUD）
- `server/internal/service/e2ee_service.go`

**REST：**

- `POST /e2ee/prekeys/upload` `{identityKey, signedPreKey, oneTimeKeys:[...]}`
- `GET /e2ee/prekey-bundle/:userId` → `{identityKey, signedPreKey, oneTimeKey}`（每次取一个 oneTime key，服务端自动删）
- `POST /e2ee/backup` `{cipherBlob, salt}` + `GET /e2ee/backup`

**验收：**

- Alice 发消息 → 服务器 DB `messages.content` 是密文（base64 加密块）
- Bob 客户端解密 + 显示明文
- Alice 换设备 → 输入 PIN → 恢复所有历史会话
- 密钥指纹页对比一致（Signal 风格 5×5 数字网格）

**风险：**

- 密钥丢失即历史不可恢复：UI 强制 PIN 备份提示
- 迁移路径：v0.9 起给用户预告 E2EE 上线时间；v1.0 灰度开关默认关，用户主动开启
